# Complete AI plugins for your job

Free plugins by Complete AI Training (https://completeaitraining.com) that turn Claude and ChatGPT into a work assistant for your job: skills for the main tasks, ready-made prompts, an app to build and the apps you can connect. Members of Complete AI Training sign in to add the daily AI news for their job, ideas and the full prompt library.

## Install in Claude Code

```
/plugin marketplace add completeaitraining/completeai-plugins
```

In claude.ai and the desktop app, find them in the plugin directory: search for "Complete AI".
