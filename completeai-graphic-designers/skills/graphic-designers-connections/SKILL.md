# Connections (MCP servers) for Graphic Designers

A connection (an MCP server) lets your AI look things up and get work done in an app you already use, like your email, files or bookkeeping software. You only add the ones for the apps you use: each connection gets access to that app, so it's always your choice, one app at a time.

## The connections that fit Graphic Designers
1. **RNV Color MCP server** (no install needed): Mix, convert, and match colors, build palettes, and save them by name, right from your chat.
   Set-up steps and a copy-and-paste install prompt: https://completeaitraining.com/mcp-servers/rnvizion-rnv-color-mcp/
2. **Colorblind Safety MCP servers**: Check if your colors and images are colorblind-safe, and see them the way a colorblind person does.
   Set-up steps and a copy-and-paste install prompt: https://completeaitraining.com/mcp-servers/vince-gonzalez-opticquiz-mcp/
3. **AI Vision MCP server**: Lets your AI look at images and videos, describe them, compare them, and check design quality.
   Set-up steps and a copy-and-paste install prompt: https://completeaitraining.com/mcp-servers/tan-yong-sheng-ai-vision-mcp/
4. **StudioMCPHub MCP server** (no install needed): Lets your AI make and edit images, prep print files, and look up museum artworks for you.
   Set-up steps and a copy-and-paste install prompt: https://completeaitraining.com/mcp-servers/codex-curator-studiomcphub/
5. **CoDesign MCP server**: Your AI can create, edit and export branded designs like social posts, flyers and print PDFs.
   Set-up steps and a copy-and-paste install prompt: https://completeaitraining.com/mcp-servers/imgly-codesign/
6. **Unsplash MCP server**: Lets your AI search Unsplash photos, collections and topics, with ready-made photo credits.
   Set-up steps and a copy-and-paste install prompt: https://completeaitraining.com/mcp-servers/hanoak-unsplash-mcp-server/
7. **Pexels MCP server**: Your AI can search free Pexels stock photos and videos and bring back links and credits.
   Set-up steps and a copy-and-paste install prompt: https://completeaitraining.com/mcp-servers/afshinator-mcp-server-pexels/
8. **webfetch MCP server** (no install needed): Your AI can search for images across many sources and tell you the license and credit line for each one.
   Set-up steps and a copy-and-paste install prompt: https://completeaitraining.com/mcp-servers/ashlrai-webfetch/
9. **Brand System MCP server**: Your AI can read your brand guidelines, make on-brand content, and check drafts against your rules.
   Set-up steps and a copy-and-paste install prompt: https://completeaitraining.com/mcp-servers/brand-system-brandsystem-mcp/
10. **Stocky stock photo MCP server**: Search and download free stock photos from Pexels and Unsplash right from your AI chat.
   Set-up steps and a copy-and-paste install prompt: https://completeaitraining.com/mcp-servers/joelio-stocky/
11. **Topaz Labs MCP server**: Let your AI improve your photos with Topaz Labs: upscale, sharpen, and clean up images for you.
   Set-up steps and a copy-and-paste install prompt: https://completeaitraining.com/mcp-servers/topazlabs-topaz-mcp/
12. **OpenAI GPT Image MCP server**: Lets your AI create and edit images with OpenAI's image models, right from the chat.
   Set-up steps and a copy-and-paste install prompt: https://completeaitraining.com/mcp-servers/surescaleai-openai-gpt-image-mcp/

## How to add one (we guide you)
1. Open the connection's page (the link above) and pick the AI you use.
2. Follow the steps there, or copy the install prompt and paste it into Claude: it checks the connection and installs it with you, step by step.
3. In ChatGPT: Settings → Apps & Connectors → Add, then paste the connection's address from its page.
4. In Microsoft 365 Copilot at work: ask your IT team to add it (the page has a section for them).

## When the user asks
- "Which apps can you connect to?": list the connections above in plain words and ask which apps they use.
- "Help me connect <app>": open the matching connection's page link and walk them through its steps one at a time. Never ask for passwords or keys in the chat: the app's own sign-in screen handles that.
