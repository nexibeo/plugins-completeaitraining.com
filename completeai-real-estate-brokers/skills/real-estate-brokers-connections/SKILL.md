# Connections (MCP servers) for Real Estate Brokers

A connection (an MCP server) lets your AI look things up and get work done in an app you already use, like your email, files or bookkeeping software. Each connection gets access to that app, so you add only the ones you choose.

## The connections that fit real estate brokers
1. **SignWell MCP server** (official): Send documents for e-signature, track who signed, and download the signed PDFs, all from your AI chat.
   About it, and how to add it: https://completeaitraining.com/mcp-servers/bidsketch-signwell-mcp/
2. **OfficeAgent MCP server** (official): Let your AI edit Word, PowerPoint and Excel files, with changes you can review before saving.
   About it, and how to add it: https://completeaitraining.com/mcp-servers/ilia-sokolov-officeagent-net/
3. **Propstack MCP server**: Let your AI search contacts, manage properties, track deals and plan viewings in your Propstack CRM.
   About it, and how to add it: https://completeaitraining.com/mcp-servers/ashev87-propstack-mcp/
4. **Box MCP server** (official) (no install needed): Let your AI search your Box files, answer questions about them, and pull out details for you.
   About it, and how to add it: https://completeaitraining.com/mcp-servers/box-mcp-server-box-remote/
5. **Zillow MCP server** (no install needed): Lets your AI search Zillow homes for sale, for rent or sold, and pull full details on any listing.
   About it, and how to add it: https://completeaitraining.com/mcp-servers/hasdata-zillow-mcp/
6. **GeoWire MCP server**: Let your AI find places, give directions, and analyze neighborhoods right inside your chats.
   About it, and how to add it: https://completeaitraining.com/mcp-servers/geowire-geowire/
7. **Cook County Property MCP server** (no install needed): Look up Chicago and Cook County property records, sales, permits and tax history by address or PIN.
   About it, and how to add it: https://completeaitraining.com/mcp-servers/hyperionxmota-cook-county-property-mcp/
8. **Pedra MCP server** (official) (no install needed): Let your AI edit real estate photos and build virtual tours through Pedra, right from the chat.
   About it, and how to add it: https://completeaitraining.com/mcp-servers/pedra-ai-pedra-mcp/
9. **MCP Emails server** (no install needed): Let your AI read, search, send and organize email in your own mailbox.
   About it, and how to add it: https://completeaitraining.com/mcp-servers/albretsen-mcpemails/
10. **Google Search MCP server (AceDataCloud)** (no install needed): Lets your AI run Google searches for web, images, news, videos, places and maps, and hand you the results.
   About it, and how to add it: https://completeaitraining.com/mcp-servers/acedatacloud-serpmcp/
11. **Fluxmail MCP server** (official): Let your AI read, search, draft, send and organize email across your mailboxes.
   About it, and how to add it: https://completeaitraining.com/mcp-servers/churichard-fluxmail/
12. **OpenStreetMap MCP server**: Lets your AI look up addresses, find nearby places, and plan routes using OpenStreetMap data.
   About it, and how to add it: https://completeaitraining.com/mcp-servers/jagan-shanmugam-open-streetmap-mcp/

## When the user asks
- "Which apps can you connect to?": list the connections above in plain words and ask which apps they use.
- "How do I connect <app>?": give the link to that connection's page. The user follows the steps on that page themselves. Do not install or set up anything, and never ask for passwords or keys in the chat.
