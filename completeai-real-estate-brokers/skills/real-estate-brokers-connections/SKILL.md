# Connections (MCP servers) for Real Estate Brokers

A connection (an MCP server) lets your AI look things up and get work done in an app you already use, like your email, files or bookkeeping software. You only add the ones for the apps you use: each connection gets access to that app, so it's always your choice, one app at a time.

## The connections that fit Real Estate Brokers
1. **SignWell MCP server** (official): Send documents for e-signature, track who signed, and download the signed PDFs, all from your AI chat.
   Set-up steps and a copy-and-paste install prompt: https://completeaitraining.com/mcp-servers/bidsketch-signwell-mcp/
2. **OfficeAgent MCP server** (official): Let your AI edit Word, PowerPoint and Excel files, with changes you can review before saving.
   Set-up steps and a copy-and-paste install prompt: https://completeaitraining.com/mcp-servers/ilia-sokolov-officeagent-net/
3. **Propstack MCP server**: Let your AI search contacts, manage properties, track deals and plan viewings in your Propstack CRM.
   Set-up steps and a copy-and-paste install prompt: https://completeaitraining.com/mcp-servers/ashev87-propstack-mcp/
4. **Box MCP server** (official) (no install needed): Let your AI search your Box files, answer questions about them, and pull out details for you.
   Set-up steps and a copy-and-paste install prompt: https://completeaitraining.com/mcp-servers/box-mcp-server-box-remote/
5. **Zillow MCP server** (no install needed): Lets your AI search Zillow homes for sale, for rent or sold, and pull full details on any listing.
   Set-up steps and a copy-and-paste install prompt: https://completeaitraining.com/mcp-servers/hasdata-zillow-mcp/
6. **GeoWire MCP server**: Let your AI find places, give directions, and analyze neighborhoods right inside your chats.
   Set-up steps and a copy-and-paste install prompt: https://completeaitraining.com/mcp-servers/geowire-geowire/
7. **Cook County Property MCP server** (no install needed): Look up Chicago and Cook County property records, sales, permits and tax history by address or PIN.
   Set-up steps and a copy-and-paste install prompt: https://completeaitraining.com/mcp-servers/hyperionxmota-cook-county-property-mcp/
8. **Pedra MCP server** (official) (no install needed): Let your AI edit real estate photos and build virtual tours through Pedra, right from the chat.
   Set-up steps and a copy-and-paste install prompt: https://completeaitraining.com/mcp-servers/pedra-ai-pedra-mcp/
9. **MCP Emails server** (no install needed): Let your AI read, search, send and organize email in your own mailbox.
   Set-up steps and a copy-and-paste install prompt: https://completeaitraining.com/mcp-servers/albretsen-mcpemails/
10. **Google Search MCP server (AceDataCloud)** (no install needed): Lets your AI run Google searches for web, images, news, videos, places and maps, and hand you the results.
   Set-up steps and a copy-and-paste install prompt: https://completeaitraining.com/mcp-servers/acedatacloud-serpmcp/
11. **Fluxmail MCP server** (official): Let your AI read, search, draft, send and organize email across your mailboxes.
   Set-up steps and a copy-and-paste install prompt: https://completeaitraining.com/mcp-servers/churichard-fluxmail/
12. **OpenStreetMap MCP server**: Lets your AI look up addresses, find nearby places, and plan routes using OpenStreetMap data.
   Set-up steps and a copy-and-paste install prompt: https://completeaitraining.com/mcp-servers/jagan-shanmugam-open-streetmap-mcp/

## How to add one (we guide you)
1. Open the connection's page (the link above) and pick the AI you use.
2. Follow the steps there, or copy the install prompt and paste it into Claude: it checks the connection and installs it with you, step by step.
3. In ChatGPT: Settings → Apps & Connectors → Add, then paste the connection's address from its page.
4. In Microsoft 365 Copilot at work: ask your IT team to add it (the page has a section for them).

## When the user asks
- "Which apps can you connect to?": list the connections above in plain words and ask which apps they use.
- "Help me connect <app>": open the matching connection's page link and walk them through its steps one at a time. Never ask for passwords or keys in the chat: the app's own sign-in screen handles that.
