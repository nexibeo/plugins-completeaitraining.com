# Build an Evidence-backed feedback report workbench

Turns raw feedback into a draft report where every summary line links back to its source comment.

- Who it is for: HR, people-analytics and customer-insight teams producing recurring feedback reports
- The problem it solves: Feedback arrives in scattered formats and platforms, and turning it into structured, reviewable reports takes manual effort and loses the link to source evidence.
- What goes in: Collected survey responses, review comments, interview notes and platform exports
- What comes out: Reviewer-approved feedback reports linked to their evidence
- See it working (online demo): https://completeaitraining.com/build-ai-apps/human-resources/evidence-backed-feedback-report-workbench/

How to help:
1. Run the two-minute version below: it builds a clickable first version right here in the chat.
2. Improve it with the user, one change at a time.

## The two-minute version

```
Build me a simple working version of an app called "Evidence-backed feedback report workbench" that I can click through right here in this chat (as an interactive page, artifact or canvas).

Who it is for: HR, people-analytics and customer-insight teams producing recurring feedback reports
The problem it solves: Feedback arrives in scattered formats and platforms, and turning it into structured, reviewable reports takes manual effort and loses the link to source evidence.
What I put in: Collected survey responses, review comments, interview notes and platform exports
What I get out: Reviewer-approved feedback reports linked to their evidence

What it should do, step by step:
1. Ingest responses, comments and notes from connected platforms
2. Normalize multiple data formats into one reviewable set
3. Apply customizable report and survey templates
4. Generate draft reports from raw inputs
5. Produce clear summaries of key points
6. Surface actionable insights beside their evidence
7. Run sentiment analysis and categorize responses
8. Prioritize feedback by theme and severity
9. Collect feedback in real time with automated notifications
10. Visualize trends and distributions in reports
11. Support reviewer collaboration and comments
12. Track goals and skill development items
13. Attach curated learning materials to development findings
14. Send reminders to keep development plans current
15. Compare the reviewed result with the recorded baseline and value assumptions
16. Capture corrections and named-owner approval before consequential use
17. Export a versioned reviewer-approved feedback report with source references and unresolved questions

Please:
- Put it all on one page and fill it with realistic sample data, so I can try it straight away.
- Make the buttons work, even if some results are simulated for now.
- I don't know how to code: don't ask me to install anything, and explain in plain language how to use it.
- When it's ready, suggest three improvements I could ask you for next.
```
