# Complete AI for Human Resources Managers

A free plugin by Complete AI Training (https://completeaitraining.com) that turns Claude into a work assistant for human resources managers. Ask for the work in your own words and it picks the right skill, asks for the details it needs, and gives you the finished result.

## What's inside
- **19 skills**, starting with **human-resources-managers-assistant**, which picks the right one for each request
- **15 ready-made prompts** for human resources managers
- **An app to build with AI**: Evidence-backed feedback report workbench. Turns raw feedback into a draft report where every summary line links back to its source comment.
- **A connections guide**: the 12 apps your AI can connect to for this job (MCP servers), like HeadHunter (hh.ru) MCP server, Box MCP server, Linked API MCP server

## Try it
- "Draft a job description for a warehouse supervisor"
- "My engagement survey scores dropped. What now?"
- "Write a PIP for an employee missing deadlines"
- "Build a 30-day onboarding plan for a new hire"

## For Complete AI Training members
The plugin includes the Complete AI Training connection (https://completeaitraining.com/mcp/plugin). It only returns information for Claude to show you; it never sends instructions, prompts or files to carry out. Members sign in once with their account. Everything it can do:
- `get_news`: the latest AI news for a job, with links
- `get_weekly_trends`: this week's AI trend article for the member's field
- `get_idea`: today's idea (or this week's ideas) for using AI in the job
- `get_learning_list`: this week's learning list and progress
- `mark_learning_item`: marks a learning item done, skipped or pinned (saved)
- `set_pace`: sets how much time the member wants to learn each week (saved)
- `get_certificates`: the member's certificates and what the next level needs
- `search_courses`: searches Complete AI Training courses, learning paths and certifications
- `find_tool`: searches the directory of AI tools for a task

Members also have the full prompt library (216 prompts for human resources managers) and 12 AI agents on https://completeaitraining.com. Without an account, everything else in the plugin works as normal. About Complete AI Training: https://completeaitraining.com/pricing/

## What this plugin does with your data
- The skills and prompts run inside Claude. The plugin itself stores nothing and sends nothing anywhere.
- The Complete AI Training connection is used only when you sign in to it, and only when you ask for something it provides. It reads your job profile, learning list and certificates. It saves only two things, when you ask: a learning item marked done, skipped or pinned, and your weekly learning pace. Privacy policy: https://completeaitraining.com/privacy-disclaimer/
- The connections guide lists other apps' MCP servers with a link to each page. It never installs or sets up anything.

## Install
- **claude.ai, the desktop app and Cowork:** find "Complete AI for Human Resources Managers" in the plugin directory and click Install. Then start a chat and type **/start**.
- **Claude Code:** `/plugin marketplace add nexibeo/plugins-completeaitraining.com`, then `/plugin install completeai-human-resources-managers@completeai-plugins`.

## Commands
- /start: what the plugin can do for you
- /prompts [task]: find a ready-made prompt
