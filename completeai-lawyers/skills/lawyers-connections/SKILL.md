# Connections (MCP servers) for Lawyers

A connection (an MCP server) lets your AI look things up and get work done in an app you already use, like your email, files or bookkeeping software. You only add the ones for the apps you use: each connection gets access to that app, so it's always your choice, one app at a time.

## The connections that fit Lawyers
1. **OfficeAgent MCP server** (official): Let your AI edit Word, PowerPoint and Excel files, with changes you can review before saving.
   Set-up steps and a copy-and-paste install prompt: https://completeaitraining.com/mcp-servers/ilia-sokolov-officeagent-net/
2. **Box MCP server** (official) (no install needed): Let your AI search your Box files, answer questions about them, and pull out details for you.
   Set-up steps and a copy-and-paste install prompt: https://completeaitraining.com/mcp-servers/box-mcp-server-box-remote/
3. **Word document MCP server**: Let your AI open, edit, and review Word files, with changes shown as tracked revisions.
   Set-up steps and a copy-and-paste install prompt: https://completeaitraining.com/mcp-servers/securityronin-docx-mcp/
4. **KitchenSink4Word MCP server**: Let your AI edit real Word documents: text, tables, tracked changes, citations and more.
   Set-up steps and a copy-and-paste install prompt: https://completeaitraining.com/mcp-servers/nometalalchemist-kitchensink4word/
5. **SignWell MCP server** (official): Send documents for e-signature, track who signed, and download the signed PDFs, all from your AI chat.
   Set-up steps and a copy-and-paste install prompt: https://completeaitraining.com/mcp-servers/bidsketch-signwell-mcp/
6. **Outlook Attachment Reader MCP server**: Let your AI open and read the files attached to your Outlook emails, and send local files as drafts.
   Set-up steps and a copy-and-paste install prompt: https://completeaitraining.com/mcp-servers/zacccck-claude-mcp-read-email-attachments/
7. **Web Researcher MCP server**: Lets your AI search trusted sites, read full articles, and give you real, clickable sources.
   Set-up steps and a copy-and-paste install prompt: https://completeaitraining.com/mcp-servers/zoharbabin-web-researcher-mcp/
8. **LibreJustice MCP server** (official) (no install needed): Search French and European case law and legal texts, and read any article as it stood on a given date.
   Set-up steps and a copy-and-paste install prompt: https://completeaitraining.com/mcp-servers/librejustice-librejustice/
9. **CanLII MCP server** (no install needed): Lets your AI look up Canadian court cases and laws by title, citation, date, and keywords.
   Set-up steps and a copy-and-paste install prompt: https://completeaitraining.com/mcp-servers/vaquill-ai-canlii-mcp/
10. **Normativa Colombia MCP server**: Consulta leyes y sentencias colombianas desde tu asistente de IA, sin abrir el navegador.
   Set-up steps and a copy-and-paste install prompt: https://completeaitraining.com/mcp-servers/angelthebestone-normativa-colombiana-mcp/
11. **Sudact MCP server**: Let your AI search Russian court decisions and pull up the full text of a case for you.
   Set-up steps and a copy-and-paste install prompt: https://completeaitraining.com/mcp-servers/atomno-mcp-mcp-sudact/
12. **LexAPI MCP server**: Look up EU laws, court cases, and citations from EUR-Lex right inside your AI chat.
   Set-up steps and a copy-and-paste install prompt: https://completeaitraining.com/mcp-servers/lex-api-lexapi-mcp/

## How to add one (we guide you)
1. Open the connection's page (the link above) and pick the AI you use.
2. Follow the steps there, or copy the install prompt and paste it into Claude: it checks the connection and installs it with you, step by step.
3. In ChatGPT: Settings → Apps & Connectors → Add, then paste the connection's address from its page.
4. In Microsoft 365 Copilot at work: ask your IT team to add it (the page has a section for them).

## When the user asks
- "Which apps can you connect to?": list the connections above in plain words and ask which apps they use.
- "Help me connect <app>": open the matching connection's page link and walk them through its steps one at a time. Never ask for passwords or keys in the chat: the app's own sign-in screen handles that.
