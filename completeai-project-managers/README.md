# Complete AI for Project managers

A free plugin by Complete AI Training (https://completeaitraining.com) that turns Claude into a work assistant for project managers. Ask for the work in your own words and it picks the right skill, asks for the details it needs, and gives you the finished result.

## What's inside
- **19 skills**, starting with **project-managers-assistant**, which picks the right one for each request
- **15 ready-made prompts** for project managers
- **An app to build with AI**: Team project coordination and communication portal. One place for task ownership and project records, so you stop chasing updates in chat threads.
- **A connections guide**: the 12 apps your AI can connect to for this job (MCP servers), like Google Workspace MCP server, Teamwork MCP server, Excel MCP server

## Try it
- "Draft a charter for our website replatform"
- "Build a RAID log from these notes"
- "Why is this project slipping? Check the plan"
- "Write this week's status report"

## For Complete AI Training members
The plugin includes the Complete AI Training connection (https://completeaitraining.com/mcp). Members sign in once with their account, and the plugin then adds:
- the daily AI news and a new idea every day for project managers ("Good morning")
- the full prompt library for project managers (300 prompts) and app build packs
- the weekly AI trends for the field

Members also get the 12 AI agents for project managers on completeaitraining.com, like the Event Run-of-Show Dependency Agent and the Cross-Team Dependency Resolution Agent: https://completeaitraining.com/ai-agents/

Without an account, everything else in the plugin works as normal. About Complete AI Training: https://completeaitraining.com/pricing/

## What this plugin does with your data
- The skills and prompts run inside Claude. The plugin itself stores nothing and sends nothing anywhere.
- The Complete AI Training connection is used only when you sign in to it. It then reads your job profile and saves your learning progress, ideas you keep and your weekly review (categories and counts only). Privacy policy: https://completeaitraining.com/privacy-disclaimer/
- The connections guide links to other apps' pages. It never installs anything by itself.

## Install
- **claude.ai, the desktop app and Cowork:** find "Complete AI for Project managers" in the plugin directory and click Install. Then start a chat and type **/start**.
- **Claude Code:** `/plugin marketplace add completeaitraining/completeai-plugins`, then `/plugin install completeai-project-managers@completeai-plugins`.

## Commands
- /start: what the plugin can do for you
- /prompts [task]: find a ready-made prompt
