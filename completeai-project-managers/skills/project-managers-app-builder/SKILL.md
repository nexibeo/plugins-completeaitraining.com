# Build a Team project coordination and communication portal

One place for task ownership and project records, so you stop chasing updates in chat threads.

- Who it is for: Team leads and operations managers running multi-person projects with distributed contributors
- The problem it solves: Task assignment, document collaboration, chat, progress reporting and AI assistants sit in separate subscriptions, so context and accountability fragment across tools.
- What goes in: Team skills, availability, project plans, documents, chat history and workflow rules
- What comes out: Reviewed task-and-progress record linked to named owners
- See it working (online demo): https://completeaitraining.com/build-ai-apps/management/team-project-coordination-and-communication-portal/

How to help:
1. Run the two-minute version below: it builds a clickable first version right here in the chat.
2. Improve it with the user, one change at a time.

## The two-minute version

```
Build me a simple working version of an app called "Team project coordination and communication portal" that I can click through right here in this chat (as an interactive page, artifact or canvas).

Who it is for: Team leads and operations managers running multi-person projects with distributed contributors
The problem it solves: Task assignment, document collaboration, chat, progress reporting and AI assistants sit in separate subscriptions, so context and accountability fragment across tools.
What I put in: Team skills, availability, project plans, documents, chat history and workflow rules
What I get out: Reviewed task-and-progress record linked to named owners

What it should do, step by step:
1. Match team members to tasks by skills and availability
2. Let multiple people edit documents and share ideas at the same time
3. Provide built-in chat and video for team communication
4. Track project progress and generate schedule reports
5. Adjust workflows to fit different project structures
6. Keep the interface simple for new users
7. Offer a no-cost tier for small teams
8. Support limited offline work with later sync
9. Handle real-time update delays during high-traffic periods
10. Keep conversations and context intact across restarts, disconnects and redeploys
11. Connect Slack, Teams and Telegram without bot tokens or webhook setup
12. Handle authentication once per app for GitHub, HubSpot, Zendesk and Jira
13. Let the AI agent ask onboarding questions and write its own configuration record
14. Run scheduled jobs, email, dashboard, browser automation, voice and calendar tasks
15. Bill by tools used, with inference metered separately and only successful actions charged
16. Use a shared workspace wallet for spending
17. Create configurable AI specialists with defined roles and persistent memory
18. Show source attribution and step-by-step reasoning
19. Let users question reasoning, redo steps and jump in mid-process
20. Retain workflow habits and preferences inside a specialist

Please:
- Put it all on one page and fill it with realistic sample data, so I can try it straight away.
- Make the buttons work, even if some results are simulated for now.
- I don't know how to code: don't ask me to install anything, and explain in plain language how to use it.
- When it's ready, suggest three improvements I could ask you for next.
```
