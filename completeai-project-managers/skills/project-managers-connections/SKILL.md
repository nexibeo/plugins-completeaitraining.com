# Connections (MCP servers) for Project managers

A connection (an MCP server) lets your AI look things up and get work done in an app you already use, like your email, files or bookkeeping software. You only add the ones for the apps you use: each connection gets access to that app, so it's always your choice, one app at a time.

## The connections that fit Project managers
1. **Google Workspace MCP server**: Lets your AI read and write your Gmail, Calendar, Drive, Docs, Sheets and more, all from one chat.
   Set-up steps and a copy-and-paste install prompt: https://completeaitraining.com/mcp-servers/taylorwilsdon-google-workspace-mcp/
2. **Teamwork MCP server** (official): Connect your AI to Teamwork so it can look up projects, tasks, tickets, and messages for you.
   Set-up steps and a copy-and-paste install prompt: https://completeaitraining.com/mcp-servers/teamwork-mcp/
3. **Excel MCP server**: Lets your AI create, read and edit Excel workbooks for you, without opening Excel.
   Set-up steps and a copy-and-paste install prompt: https://completeaitraining.com/mcp-servers/haris-musa-excel-mcp-server/
4. **WayStation MCP server** (no install needed): Connect your AI to Notion, Slack, Jira, Airtable and other work apps so it can look things up and update them for you.
   Set-up steps and a copy-and-paste install prompt: https://completeaitraining.com/mcp-servers/waystation-ai-mcp/
5. **Google Sheets MCP server**: Lets your AI read, write, and manage your Google Sheets for you, right from the chat.

## How to add one (we guide you)
1. Open the connection's page (the link above) and pick the AI you use.
2. Follow the steps there, or copy the install prompt and paste it into Claude: it checks the connection and installs it with you, step by step.
3. In ChatGPT: Settings → Apps & Connectors → Add, then paste the connection's address from its page.
4. In Microsoft 365 Copilot at work: ask your IT team to add it (the page has a section for them).

## When the user asks
- "Which apps can you connect to?": list the connections above in plain words and ask which apps they use.
- "Help me connect <app>": open the matching connection's page link and walk them through its steps one at a time. Never ask for passwords or keys in the chat: the app's own sign-in screen handles that.
