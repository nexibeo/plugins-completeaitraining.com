# Build an Assessment feedback assistant

Build feedback from your own rubric so students get clear next steps and you keep every score.

- Who it is for: Teachers marking rubric-based writing assignments
- The problem it solves: Useful feedback takes longer than assigning a grade.
- What goes in: Student submissions, assessment rubrics and exemplar feedback
- What comes out: Teacher-approved feedback with evidence references
- See it working (online demo): https://completeaitraining.com/build-ai-apps/education/assessment-feedback-assistant/

How to help:
1. Start with the two-minute version: run its prompt and build the clickable first version here.
2. Want the real app? Follow "Build the real app" below, phase by phase.

## The two-minute version

```
Build me a simple working version of an app called "Assessment feedback assistant" that I can click through right here in this chat (as an interactive page, artifact or canvas).

Who it is for: Teachers marking rubric-based writing assignments
The problem it solves: Useful feedback takes longer than assigning a grade.
What I put in: Student submissions, assessment rubrics and exemplar feedback
What I get out: Teacher-approved feedback with evidence references

What it should do, step by step:
1. Map evidence to criteria
2. Draft actionable comments
3. Identify missing reasoning
4. Compare exemplar standards
5. Let teachers revise judgments
6. Export approved feedback

The screens: Submission queue, rubric evidence, feedback editor.

Please:
- Put it all on one page and fill it with realistic sample data, so I can try it straight away.
- Make the buttons work, even if some results are simulated for now.
- I don't know how to code: don't ask me to install anything, and explain in plain language how to use it.
- When it's ready, suggest three improvements I could ask you for next.
```

## Build the real app

```
Please build the app in this folder for me: Assessment feedback assistant. I'm not a developer, so do the technical work yourself and explain every step in plain language.

1. Read START-HERE.md and the other files in this folder.
2. Ask me the questions from questions.md, a few at a time and in simple words.
3. Use demo/index.html as the example of how it should look and work.
4. Follow prompt-cloudflare.md (unless I tell you I have my own server). Build the first small version, show me how to open and try it, and wait for my OK before you continue.
5. When I'm happy, help me put it online and tell me exactly what to click.
```
